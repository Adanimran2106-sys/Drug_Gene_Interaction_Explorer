# Drug–Gene Interaction Explorer

A Python bioinformatics project that explores drug–gene interaction data using the DGIdb dataset.

## Features

- Loads and cleans a real-world drug–gene interaction dataset (DGIdb)
- Analyzes top drugs by number of gene targets
- Analyzes top genes by number of drugs targeting them
- Visualizes results as bar charts
- Interactive command-line explorer to search interactions by drug or gene name
